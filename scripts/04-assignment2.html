Assignment 2 – TCO Presentation

Total Cost of Ownership (TCO) Analysis

This page contains Assignment 2 for ICT171 Introduction to Server Environments and Architectures (S1, 2026).

The presentation analyses the Total Cost of Ownership (TCO) of different cloud service models, focusing on Infrastructure as a Service (IaaS) and Software as a Service (SaaS).

For the IaaS solution, Microsoft Azure was selected as the cloud platform. Azure provides virtual machines, networking, storage, and infrastructure resources that allow full control over the server environment. This model offers flexibility, scalability, and customization for hosting cloud-based applications and monitoring systems.

For the SaaS solution, Datadog was evaluated as a cloud-based monitoring platform. Datadog provides monitoring and analytics services through a subscription model, eliminating the need for users to manage servers or infrastructure. While SaaS solutions are easier to deploy and maintain, they may offer less customization and control compared to IaaS environments.

The presentation compares both solutions based on implementation cost, operational expenses, scalability, maintenance requirements, management overhead, security considerations, flexibility, and long-term value. The analysis highlights the advantages and disadvantages of each cloud service model for a cloud-based monitoring environment.

Based on the TCO evaluation, Microsoft Azure (IaaS) was selected as the preferred solution because it provides greater flexibility, customization, and control over the monitoring environment while remaining cost-effective for the project requirements.
